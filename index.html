Sistem Prediksi Keterlambatan Kredit (Fuzzy Tsukamoto)
Deskripsi Proyek (Tugas Akhir S1)

Proyek Tugas Akhir Sarjana yang mengembangkan aplikasi berbasis web untuk memprediksi tingkat risiko keterlambatan pembayaran kredit sepeda motor. Sistem ini memanfaatkan kecerdasan buatan berbasis logika Fuzzy Tsukamoto guna membantu analis kredit dalam mengambil keputusan pembiayaan yang objektif dan terukur.

Fitur Utama & Alur Sistem
  • Implementasi metode Fuzzy Tsukamoto (Fuzzifikasi, Pembentukan Aturan Implikasi, dan Defuzzifikasi).
  • Pengolahan dan normalisasi variabel data debitur (penghasilan, riwayat pembayaran, jumlah tanggungan, dan nilai angsuran).
  • Kalkulasi otomatis skor risiko keterlambatan secara transparan dan akurat.
  • Pengujian hasil prediksi dan komparasi akurasi menggunakan tools MATLAB dan Excel.
Teknologi yang Digunakan
PHP MySQL Fuzzy Tsukamoto MATLAB Ms. Excel
Peran & Kontribusi

Merancang arsitektur sistem dari awal, melakukan formulasi fungsi keanggotaan logika Fuzzy, penulisan algoritma perhitungan pada server PHP, serta validasi hasil prediksi dengan data riil.
