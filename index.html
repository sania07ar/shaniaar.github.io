Aurora Hotel Reservation System
Deskripsi Proyek

Aurora Hotel Reservation System adalah aplikasi berbasis web yang dirancang untuk mempermudah proses pemesanan kamar hotel secara terstruktur dan efisien. Sistem ini mengatasi kendala pencatatan manual dengan menyediakan pengelolaan ketersediaan kamar secara real-time dan perhitungan biaya yang akurat.

Fitur Utama Sistem
  • Katalog kamar lengkap dengan rincian fasilitas, tipe bed, dan tarif per malam.
  • Formulir reservasi interaktif dengan pemilihan tanggal check-in dan check-out.
  • Kalkulasi otomatis total biaya berdasarkan durasi menginap dan tipe kamar yang dipilih.
  • Dashboard admin untuk mengelola status pemesanan, data tamu, dan laporan reservasi.
Teknologi yang Digunakan
PHP MySQL Database Bootstrap 5 JavaScript (DOM) XAMPP Server
Peran & Kontribusi Saya

Sebagai developer utama, saya bertanggung jawab penuh atas perancangan skema database MySQL, penulisan logika pemesanan di sisi server menggunakan PHP, serta pembangunan antarmuka halaman publik dan panel admin yang responsif.
